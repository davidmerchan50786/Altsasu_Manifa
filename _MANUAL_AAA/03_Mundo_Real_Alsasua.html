4 · Procedimiento de datos (orden recomendado)

4.1 Relieve (DEM)

  • Descarga el MDT/LIDAR del Centro de Descargas del IGN o de IDENA (Navarra) para la hoja de Alsasua. Resoluciones: MDT05 (5 m) base; LIDAR (0.5–2 m) para el casco urbano.
  • Ejecuta python PipelineLIDAR_Completo.py para generar el heightmap. Salida esperada: Assets/AlsasuaData/dem_unity_1025.raw (1025×1025, 16-bit).
  • Verifica en Unity que el terreno coincide con el relieve real (el valle baja hacia el río, Aralar al sur).
El juego ya tiene dtm_alsasua_5m.asc, lidar_ground.xyz y dem_unity_1025.raw. Solo regenéralos si quieres más precisión o ampliar el área.

4.2 Edificios y calles (OSM)

El juego consume tres JSON en Assets/Resources/ (o donde los lea GeneradorMundoOSM):

buildings_unity.json   →  footprints + altura + tipo de los 1030 edificios
roads_unity.json       →  400 tramos con ancho y wayID
trees_unity.json       →  especie + posición de árboles

Para regenerarlos desde OSM con Overpass (área de Alsasua):

# Bounding box aprox de Alsasua (sur,oeste,norte,este)
# 42.875,-2.190,42.910,-2.140
import requests, json
Q = """
[out:json][timeout:120];
(
  way["building"](42.875,-2.190,42.910,-2.140);
  way["highway"](42.875,-2.190,42.910,-2.140);
  node["natural"="tree"](42.875,-2.190,42.910,-2.140);
);
out body geom;
"""
r = requests.get("https://overpass-api.de/api/interpreter", params={"data": Q})
open("osm_alsasua.json","w",encoding="utf-8").write(r.text)

Luego conviértelo al formato Unity (proyección lat/lon → metros con origen Herriko Plaza). Tus scripts DescargarDatosCompletos.py ya hacen este paso; revisa que el origen sea OX=1918/OZ=8570.

OSM no trae la altura de todos los edificios. Donde falte building:levels, estima por tipo (casa 2 plantas, bloque 4–6, nave 1 alta). Mejor aún: cruza con catastro para alturas reales.

4.3 Ortofoto (el toque que hace "reconocible" el pueblo)

  • Descarga la ortofoto PNOA (IGN) o WMS de IDENA para el bounding box, máxima resolución.
  • Proyéctala sobre el terreno como textura base (el proyecto tiene AplicadorOrtofoto y Assets/EscenarioSuelo/Alsasua_Color.png).
  • Para fachadas reales, usa fotos de calle (las tuyas) con TexturizadorEdificiosReales (portar de v2).

IDENA e IGN son datos abiertos oficiales: úsalos sin problema citando la fuente. OSM es ODbL (atribución). Es la vía legal y precisa para clavar Alsasua.

6 · Validación: "¿se ve que es Alsasua?"

  • Compara una captura cenital del juego con la ortofoto real: el trazado de calles debe coincidir.
  • Herriko Plaza en el centro, estación al este, N-1 cruzando, río Burunda y vía del tren en su sitio.
  • El perfil de Aralar al fondo coincide con la silueta real.
  • Alturas de edificios plausibles (no todos iguales).
