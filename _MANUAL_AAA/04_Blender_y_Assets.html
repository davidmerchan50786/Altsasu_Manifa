3 · Blender — flujo de trabajo

3.1 Importar / exportar

  • Importa tus modelos a Blender, limpia (aplica transformaciones, recalcula normales, elimina geometría interna invisible).
  • Exporta a FBX o glTF/glb para Unity. Escala correcta: 1 unidad Blender = 1 m.
  • Tienes ConvertirGLB.py y ExtraerAnimaciones.py para automatizar conversiones.

3.2 LODs (clave para 60 fps en mundo grande)

  • Por cada edificio/coche/árbol importante, genera LOD0 (cerca), LOD1 (~50%), LOD2 (~20%), LOD3 (impostor/billboard).
  • En Blender usa el modificador Decimate para LOD1–LOD2.
  • En Unity añade un LODGroup (lo automatiza LODGenerador, portar de v2).

3.3 Edificios estilo Alsasua

  • Construye un kit modular: muros de piedra/enfoscado, ventanas con contraventanas, balcones de forja, tejados a dos aguas con teja roja, aleros. Es el look de Sakana.
  • El generador procedural ya monta fachadas; el kit de Blender es para los edificios "hero" (iglesia, ayuntamiento, estación, frontón).
  • Modela los hitos reconocibles a mano: Herriko Plaza, ayuntamiento, iglesia, estación de tren, frontón. Son los que hacen decir "¡es Alsasua!".

3.4 Script Blender (ejemplo: exportar todo a glb con LODs)

import bpy, math
# Ejemplo mínimo: decimar copia para un LOD y exportar glb
def make_lod(obj, ratio):
    lod = obj.copy(); lod.data = obj.data.copy()
    bpy.context.collection.objects.link(lod)
    m = lod.modifiers.new("dec","DECIMATE"); m.ratio = ratio
    return lod

4 · Texturas PBR (que se vea AAA)

  • Cada material necesita: Albedo (Base Color), Normal (OpenGL), ARM (AO+Roughness+Metallic) y, opcional, Height/Displacement.
  • Tienes este set en Assets/Textures_AAA/. Para lo que falte, descarga de Poly Haven/ambientCG (CC0).
  • En HDRP, usa el shader Lit con mapas: Base Map, Normal Map, Mask Map (ARM empaquetado).
  • Para charcos/calles mojadas tras lluvia, sube Smoothness y usa SSR (lo gestiona SistemaSuperficiesMojadas, portar de v2).

5 · Audio

  • Motor de coche (capas: ralentí, aceleración, deceleración), pasos por superficie, ambiente de pueblo (pájaros, viento, campanas), multitud/manifestación, lluvia/tormenta, música.
  • Gestionado por AudioManager (pool de 32 fuentes, 48 clips) + SistemaMusica + SistemaReverbZonas.
  • Fuentes legales: Freesound (CC0), tus propias grabaciones del pueblo (lo más auténtico).
